# PortfolioHUB - Pedro Henrique

Este é meu PortfolioHUB, feito para a entrega final de implantação com GitHub e apoio de IA. A ideia foi criar uma página simples para mostrar meus projetos e carregar meus repositórios públicos do GitHub de forma automática.

## Objetivo

Meu objetivo foi reunir meus projetos em um só lugar e mostrar que consegui trabalhar com:

- planejamento da implantação;
- integração com GitHub;
- organização de usuários e segurança;
- controle de versão e colaboração;
- testes e publicação no GitHub Pages;
- uso de IA como apoio no processo.

## IAs utilizadas

- Google Gemini: usei como apoio para entender melhor as etapas do desafio e revisar a implantação.
- ChatGPT: usei para revisar textos, corrigir erros e melhorar a organização do site.
